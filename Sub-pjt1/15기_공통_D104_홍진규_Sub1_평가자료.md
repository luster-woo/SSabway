# 15기 공통 프로젝트 Sub1 평가자료
- 반: D104
- 이름: 홍진규
- 프로젝트명: sabway(싸브웨이)
- 주제: Vision AI 기반 외국인 철도역 내 이동 동행 서비스

## 이번 주 수행 내용

### 1. 아이디어 제안, 문제 정의, 서비스 기획
- 외국인 관광객이 복잡한 철도역 내부에서 환승 경로, 승강장, 출구를 찾기 어려운 문제를 정의했습니다.
- GPS가 동작하지 않는 지하 공간에서 표지판 촬영을 통해 현재 위치를 파악하고, 목적지 출구까지 안내하는 서비스 흐름을 설계했습니다.
- 교통카드 보유 여부에 따라 승차권 발매기, 편의점, ATM을 경유하도록 맞춤 경로를 구성했습니다.

### 2. 핵심 기능 구체화(팀 공통)
- 표지판 촬영 기반 현재 위치 인식
- 교통카드 보유 여부에 따른 맞춤 경로 안내
- 발매기 단계별 발권 가이드
- Vision AI 기반 목표 표지판 탐색 및 일치 여부 판별
- 노선·방면 분석을 통한 오방향 감지 및 경로 복구
- WebRTC 기반 실시간 영상 상담
- 영어·중국어·일본어 등 다국어 안내

### 3. 위치 인식 및 경로 탐색 방식 설계
- 대구역을 대상으로 층별 2D 지도를 직접 제작하고, 갈림길·개찰구·승강장·출구 등을 노드와 엣지로 표현하기로 했습니다.
- 각 노드에서 여러 방향의 기준 이미지를 수집하고, 사용자 촬영 이미지와의 유사도를 비교해 현재 위치 후보를 찾는 방식을 검토했습니다.
- 이미지 유사도, OCR 결과, 이전 이동 노드를 함께 활용해 위치를 판정하고, 그래프 기반 최단 경로를 제공하도록 설계했습니다.

### 4. AI 데이터 및 추론 파이프라인 정리
- 현장 이미지 수집 → 노드별 라벨링 → 이미지 전처리 → 모델 학습 → 기준 이미지 임베딩 저장의 데이터 파이프라인을 정리했습니다.
- 실시간 추론은 스마트폰(웹) → 배포 서버 → GPU 추론 서버 → 배포 서버 → 스마트폰(웹) 구조로 설계했습니다.
- 기준 이미지 임베딩을 사전에 계산하고, 실시간에는 사용자 이미지 임베딩만 추출해 응답 시간을 줄이도록 했습니다.
- OpenCV 특징점 매칭과 Vision AI 임베딩 모델의 장단점을 비교하고, OCR·그래프 정보와 결합하는 방식을 검토했습니다.

## 이번 주 학습 및 느낀 점
- AI 모델의 성능뿐 아니라 실제 서비스에서는 서버 구성, 네트워크 지연, 장애 대응이 중요하다는 점을 확인했습니다.
- 이미지 한 장만으로 위치를 확정하기보다 OCR, 이전 이동 경로, 그래프 연결 관계를 함께 활용해야 정확도를 높일 수 있음을 배웠습니다.
- 기능을 많이 추가하는 것보다 대구역이라는 제한된 공간에서 실제로 동작하는 핵심 흐름을 완성하는 것이 중요하다고 판단했습니다.

## 다음 주 계획

- 노드·엣지 데이터 구조와 이미지 라벨링 규칙을 확정합니다.
- 기준 이미지 수집 가이드라인과 촬영 시나리오를 작성합니다.
- 배포 서버와 GPU 추론 서버 간 API 통신 구조를 구현합니다.
